# NutriFlow AI
Repositório inicial do NutriFlow AI. Este diretório foi criado para organizar o desenvolvimento do produto, mas ainda não contém a aplicação: a stack, os requisitos detalhados e o código existente precisam ser adicionados quando estiverem disponíveis.
## Próximos passos
1. Definir e documentar os requisitos do produto e o público-alvo.
2. Escolher a stack com base nos requisitos e atualizar `AGENTS.md`.
3. Implementar a aplicação em uma branch de tarefa.
4. Rodar os comandos de validação definidos pelo projeto.
5. Revisar e integrar por pull request após aprovação.
Veja [docs/AI_COLLABORATION.md](docs/AI_COLLABORATION.md) e [docs/AI_TASK_TEMPLATE.md](docs/AI_TASK_TEMPLATE.md) para o fluxo de trabalho com Codex e Claude Code.
